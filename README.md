# Demon Princess Picks

> A browser game where all you do is pick one of three. Battles run on their own.

Work in progress: the game is playable from start to finish, with boxes standing in for the art and every number provisional.

## 🛠 Tech Stack

- Next.js (App Router) + React + TypeScript
- Tailwind CSS
- No server or database: a run lives entirely in the browser
- English and Japanese, following the device language

## 🚀 Development

```bash
pnpm install
pnpm dev
```

| command          | what it does                                                             |
| ---------------- | ------------------------------------------------------------------------ |
| `pnpm test`      | game logic, design rules, and balance checked by bots playing 1,000 runs |
| `pnpm lint`      | ESLint                                                                   |
| `pnpm typecheck` | TypeScript                                                               |
